Enabling Handlers

Overview

Palladium

  • Conditional
  • Key Bind

Conditional

Enables the ability for as long as the given conditions are fulfilled. You can also skip the handler object and just put the condition(s) straight into the 'enabling' field, it does the same thing.

Settings:

Setting Type Description Required Fallback Value
conditions Condition | Condition[] The condition(s) that need to be fulfilled for the ability to be enabled. true /

Examples:

{"type":"palladium:conditional","conditions":{"type":"palladium:crouching"}}
{"type":"palladium:conditional","conditions":[{"type":"palladium:crouching"},{"type":"palladium:on_ground"}]}

Key Bind

Enables the ability when the player presses a key. What exactly happens on a key press depends on the behaviour.

Settings:

Setting Type Description Required Fallback Value
cooldown Integer | Time String ("40s", "2m", etc.) | (Dynamic) Value Time the player has to wait before the ability can be used again. For 'activation' the cooldown starts right when the key is pressed, for 'toggle' and 'held' it starts once the ability turns off. 0 means no cooldown. false 0
behaviour "activation" | "toggle" | "held" How the ability reacts to the key. 'activation' turns it on for a set time after a single press, 'toggle' switches it on and off with each press, and 'held' keeps it on for as long as the key is held down. false activation
key_bind Key Bind Type The key that is used for the ability. By default this is the ability key matching the ability's slot in the ability bar. false palladium:ability_key
time Integer | Time String ("40s", "2m", etc.) | (Dynamic) Value Depends on the behaviour. For 'activation' it's how long the ability stays on after pressing the key (at least 1 tick). For 'toggle' and 'held' it's the maximum time the ability can stay on before it turns off by itself, 0 means there is no limit. false 0

Examples:

{"type":"palladium:key_bind"}
{"type":"palladium:key_bind","behaviour":"toggle","cooldown":100,"time":200}
{"type":"palladium:key_bind","key_bind":{"type":"palladium:jump","cancel_jump":true},"behaviour":"held","cooldown":40}
