Ability Animation Timer Value Integer

Returns the value of the animation timer for the specified ability. Defaults to 0 if no ability or animation timer was found.

Settings:

Setting Type Description Required Fallback Value
modify MoLang MoLang function to modify the value. false /

Examples:

{"type":"palladium:ability_animation_timer_value","ability":"namespace:example_power#ability_key"}

Beam Charge Double

Scales a value by how charged the shot of a charged argon:energy_beam was. Use it in that beam's damage, knockback or lift. Multiplies "value" by "min" at no charge and "max" at full charge.

Settings:

Setting Type Description Required Fallback Value
min Double The multiplier at the lowest charge. false 1.0
max Double The multiplier at full charge. false 1.0
value (Dynamic) Value The value to scale. true /

Examples:

{"type":"argon:beam_charge","value":10,"max":2.0}

Flight Speed Double

A flight speed that follows an argon:flight_speed_adjuster dial: "base" plus the dial's value divided by its division_amount. Use it for a flight type's "speed" and "sprint_speed". Just "base" while the ability is off.

Settings:

Setting Type Description Required Fallback Value
ability Ability Reference The flight speed adjuster ability whose dial to follow. true /
base Double The speed with the dial at zero; the dial's bonus is added to this. false 0.0

Examples:

{"type":"argon:flight_speed","ability":"example:power#flight_speed_adjuster","base":1.5}

Item Custom Value Double

A number a Tech Table module wrote onto the item in the given slot with its "argon:custom_value" effect, under the name given there. Uses the fallback if the item has no such value.

Settings:

Setting Type Description Required Fallback Value
slot "mainhand" | "offhand" | "head" | "chest" | "legs" | "feet" | "body" | "curios:head" | "curios:necklace" The slot whose item to read, e.g. an armor slot or a curios slot. true /
fallback Double What to use when the item does not have the value. false 0.0
key String The name the value was given in the module's effect. true /

Examples:

{"type":"argon:item_custom_value","slot":"chest","key":"example:core_power"}

Smoothed Double

A number that slides toward another value at a steady speed instead of jumping, so stepped values like a beam's range change smoothly. Each entity has its own figure, which restarts if unread for half a second.

Settings:

Setting Type Description Required Fallback Value
fall_speed Double How far it moves towards a lower value each second; the same as "speed" if left out. false 0.0
value (Dynamic) Value The value to follow. true /
speed Double How far it moves towards a higher value each second, in the wrapped value's own unit. true /

Examples:

{"type":"argon:smoothed","value":10,"speed":12.0,"fall_speed":12.0}
