Block on Head

Renders a block on the top of the entity's head.

Settings:

Setting Type Description Required Fallback Value
block Block Tag ID of the block/block state definition true /

Examples:

{"type":"palladium:block_on_head","block":{"Name":"minecraft:glass"}}

Compound Render Layer

A compound render layer that can contain multiple render layers.

Settings:

Setting Type Description Required Fallback Value
layers Render Layers The list of render layers this compound render layer contains. true /

Lightning Sparks

Renders lightning sparks around the entity.

Settings:

Setting Type Description Required Fallback Value
amount Integer The amount of sparks to spawn during each occurence. false 5
render_settings Laser Renderer Settings The render settings for the sparks. true /
model_parts String | String[] Model parts the sparks are limited to, like "right_arm" or "head". Each spark picks one of them and stays inside the box of that part, moving along with it. Nested parts can be written as a path like "body.cape". If none are specified, the sparks fill the whole hitbox of the entity. false /
frequency Float The frequency of the sparks. false 0.5

Examples:

{"type":"palladium:lightning_sparks","frequency":0.2,"amount":10,"render_settings":{"glow":"#0000ff","bloom":2,"size":2.0}}
{"type":"palladium:lightning_sparks","amount":4,"render_settings":{"glow":"#ffff00","bloom":2},"model_parts":["right_arm","left_arm"]}

Default Render Layer

Default render layer that renders a model with a texture.

Settings:

Setting Type Description Required Fallback Value
light_emission (Dynamic) Value The light emission of the model. Must be within 0 - 15 false 0
texture Identifier | Dynamic Texture | Texture Reference The texture to render the model with. true /
model_layer Model Layer The model layer to render. Can be a plain model layer like "example:model#main", or an object with a "base" and "variables" to switch between model layers while rendering, the same way dynamic textures do. false minecraft:player
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type to render the model with. false minecraft:entity_translucent

Examples:

{"type":"palladium:render_layer","model_layer":{"wide":"example:wide_model","slim":"example:slim_model"},"texture":{"wide":"example:wide_texture","slim":"example:slim_texture"},"light_emission":5}

Thrusters

Renders thrusters on the end of each limb of the player.

Settings:

Setting Type Description Required Fallback Value
bloom_texture Identifier | Dynamic Texture | Texture Reference The texture of the camera-facing bloom rendered at each thruster. false palladium:textures/entity/thruster_bloom.png
bloom_scale Double Size multiplier for the bloom, relative to the thruster part. Set to 0 to disable. false 1.5
color Color The color of the thrusters. true /
texture Identifier | Dynamic Texture | Texture Reference The texture to render the thrusters with. false palladium:textures/entity/thruster.png
bloom_color Color The color of the bloom. false #EAB62B
scale Vector 3D Scale for the thruster false [I@348839e
anchors string[] Bones of the player model where the thruster will be attached to false [Ljava.lang.Object;@3fd963f3

Examples:

{"type":"palladium:thrusters","color":"#ffffff","bloom_color":"#ffffff","bloom_scale":1.5}
{"type":"palladium:thrusters","texture":"mypack:thruster_texture_path","scale":[1.0,2.0,1.0],"anchors":["head","right_leg"],"color":"#ff0000","bloom_color":"#ff0000","bloom_scale":2.0}

Vibration

Renders a vibration effect on the entity.

Settings:

Setting Type Description Required Fallback Value
intensity Integer The intensity of the vibration, i.e. how many offset copies of the entity get blended in. Values above 32 are capped. true /
fade_ticks Integer | Time String ("40s", "2m", etc.) The time/ticks it needs for the vibration to fade in/out. true /

Examples:

{"type":"palladium:vibration","intensity":10}

Anchored Lightning Sparks

Like Palladium's Lightning Sparks, but sparks can be anchored to named body-part bones instead of spawning anywhere in the bounding box, using the same "anchors" as the Thrusters layer.

Settings:

Setting Type Description Required Fallback Value
amount Integer The amount of sparks to spawn during each occurence, per anchor (or once for the whole entity if "anchors" is empty). false 5
render_settings Laser Renderer Settings The render settings for the sparks. true /
offset Vector 3D [x, y, z] offset applied after positioning at the anchor (or the whole entity, if "anchors" is empty) - lets sparks sit slightly away from the bone's exact pivot instead of centered on it. false [0.0, 0.0, 0.0]
shrink_player_parts string[] Player model parts to shrink while this layer renders, as for every pack render layer. false []
anchors string[] Bones of the player model to spawn sparks at, e.g. "head", "right_arm" - each gets its own independent spark cycle. Empty (the default) spawns sparks randomly across the whole entity, matching palladium:lightning_sparks. false []
frequency Float The frequency of the sparks. false 0.5
anchor_size Float Only relevant when "anchors" isn't empty: how far, in blocks, sparks jitter from the anchor point. false 0.3

Examples:

{"type":"argon:anchored_lightning_sparks","frequency":0.2,"amount":10,"render_settings":{"glow":"#0000ff","bloom":2,"size":2.0},"anchors":["head","right_arm"],"anchor_size":0.25,"offset":[0.0,0.1,0.0]}

Cloth Render Layer

Renders a physically simulated cloth grid (a cape, by default) that flows, bends and trails behind the wearer instead of rotating as a rigid plane.

Settings:

Setting Type Description Required Fallback Value
taper Float Only meaningful for a "back" attachment: the width at the shoulders (the pinned edge) as a fraction of the full width at the hem, from 0.05 to 1. Below 1 the cloth is a trapezoid that is narrow at the shoulders and flares out to "width" at the hem, like a cape. 1 = a plain rectangle. false 1.0
aerodynamics { airflow_strength, turn_inertia, flight_stabilization, flight_stiffness_multiplier, stiffness_response, body_hug, hug_start, limb_collision, narrowing, flutter } How the cloth reacts to the wearer's real speed, not the selected flight level. Keys: airflow_strength (1), turn_inertia (1), flight_stabilization (0.6, calms swinging at speed), flight_stiffness_multiplier (1.15), stiffness_response (0.1) and body_hug (0.75, how tightly a back cape is pulled against the body near top speed) and hug_start (0.6, how far through the speed range the hugging begins). "narrowing" (not for "waist"): { enabled, start_fraction (0.25) and full_fraction (0.85) of the wearer's top flight speed, start_speed (10 blocks/s) and full_speed (40) when there is no flight, maximum (0.6; 0.35 when "wrap" is above 0 or for arms), compression (0.5, how much of the narrowing squeezes the cloth itself instead of folding it), response (0.06), recovery (0.04), distribution (1.5, higher keeps the top wider), fold (1, 0 turns the pleats off) }. "limb_collision" (back capes): { enabled (true), torso: { width (0.5), depth (0.25), length (1.1), radius (0.1) }, head: { width (0.5), depth (0.5), length (0.5), radius (0.1) }, arms: { radius (0.3), length (0.8) }, legs: { radius (0.25), length (0.8) } }, the shapes the cloth is kept out of. "flutter": { intensity (1), frequency (1), speed_influence (1), damping (0.6), edge_multiplier (1.5) }. false {}
texture Identifier | Dynamic Texture | Texture Reference The texture to render the cloth with. UVs are stable across the whole grid regardless of how the cloth deforms. true /
shrink_player_parts string[] Player model parts to shrink while this layer renders, as for every pack render layer. false []
segments Vector 2D [segments_x, segments_y]: simulation columns/rows. More = smoother bending at a performance cost. false [4, 8]
depth Float Waist attachment only: half-depth of the box's front and back sides, in blocks. Usually smaller than "width", since players are thinner front to back. Defaults to "width". false /
attachment "back" | "left_arm" | "right_arm" | "waist" Which part of the cloth grid is pinned to the wearer: "back" (cape), "left_arm" or "right_arm" (draped along an arm), or "waist" (skirt or kilt, a box-shaped loop around the hips). false back
material Identifier | Inline Material Object A registered material id (e.g. "argon:heavy") or an inline object overriding individual physics properties. false argon:standard
size Vector 2D [length, width] of the cloth at rest, in blocks. For a "waist" attachment, "width" is instead the HALF-WIDTH of its box cross-section's left/right sides (not a flat width) - see "depth" for the front/back sides. false [1.8, 1.0]
attach Vector 3D [x, y, z] offset of the attach point from the neck, in wearer space: Y=0 is neck height and increasing Y moves DOWN; a cape needs a positive Z to sit behind. For "waist", use X=0, Z=0 and Y about 0.75-0.9. false [0.0, 0.1, 0.4]
wrap Float Only meaningful for a "back" attachment: curves the pinned edge's rest shape forward so it hugs the wearer's sides, turning a flat cape into a wrap-around cloak. 0 = flat. false 0.0
pitch_influence Float Waist attachment only: while crouching, the garment follows the body's pitch as one rigid piece. This scales how much, from 0 (ignored) to 1 (fully). false 0.6
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type to draw the cloth with. false minecraft:entity_translucent
hem_pitch_fraction Float Currently unused - kept only so existing configs that set it don't fail to load. false 0.25

Examples:

{"type":"argon:cloth","texture":"example:textures/models/capes/red_cape.png"}
{"type":"argon:cloth","material":"argon:heavy","size":[2.4,1.6],"segments":[5,10],"wrap":0.6,"texture":"example:textures/models/cloaks/heavy_cloak.png"}
{"type":"argon:cloth","attachment":"left_arm","material":"argon:lightweight","size":[1.2,0.5],"segments":[3,6],"attach":[-0.3,0.2,0.0],"texture":"example:textures/models/arm_cloth.png"}
{"type":"argon:cloth","attachment":"waist","material":"argon:leather","size":[0.32,0.28],"segments":[16,6],"depth":0.1599999964237213,"pitch_influence":0.5,"attach":[0.0,0.64,0.0],"texture":"example:textures/models/skirts/skirt.png"}

Fade Render Layer

Wraps another render layer and draws it at a changing opacity so it can fade in and out. Put the wrapped layer's conditions inside "layer". Nothing is drawn at opacity 0.

Settings:

Setting Type Description Required Fallback Value
opacity Float / Value (Dynamic) 0-1: how opaque the wrapped layer is drawn. Typically the eased animation timer of an ability, e.g. palladium.get_animation_timer_eased('namespace:power#ability'), which already runs 0 to 1. false 1.0
layer Render Layer The render layer to draw, written exactly as it would be on its own, including its "conditions". true /

Examples:

{"type":"argon:fade","opacity":{"type":"palladium:molang_float","molang":"palladium.get_animation_timer_eased('example:power#some_ability')"},"layer":{"texture":{"type":"palladium:eye_selection","color":"#6b6b6b"}}}
