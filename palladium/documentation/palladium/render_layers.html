Sunstone Barrier Render Layer

A shell of sunstone grains around the wearer, the same material as fsang:sunstone_cape used as a protective mass. How much of it there is comes from "amount", a value meant to follow an ability's animation timer: at 0 nothing is drawn, and as it rises the grains appear one by one while the shell grows out from the body to its full radius. Driven from the same timer as a sunstone cape's "dispersion", it reads as the cape's material moving out to surround the wearer. It is purely visual.

Settings:

Setting Type Description Required Fallback Value
sparkle Float 0-1: the share of grains that catch the light as a bright glint. false 0.08
amount Float / Value (Dynamic) 0-1: how much of the barrier is present. 0 draws nothing. false 0.0
light_emission Integer / Value (Dynamic) 0-15: makes the grains glow. With one of Argon's glow render types (argon:glow_emission, argon:additive_emission) it is the brightness itself; with any other render type it is a light level they are lit to at least. 0 leaves the world light alone. false 0
thickness Float 0-1: how deep the shell is, as a share of its radius. Grains sit at random depths within it. false 0.25
texture Identifier | Dynamic Texture | Texture Reference The texture the grains take their color from; each grain uses a random spot on it. Use the same texture as the cape. true /
shrink_player_parts string[] As for every pack render layer: player model parts to shrink while this layer renders. false []
center_height Float Height of the shell's centre above the wearer's feet, in blocks. false 0.9
tint Color Multiplied onto the grains' color. false #FFFFFF
grain_size Vector 2D [smallest, largest] size of a grain, in blocks. Most are near the smallest. false [0.03, 0.09]
grains Integer 0-1024: how many grains make up the shell. Fewer are drawn with distance. false 240
spin_speed Float 0-8: how fast the grains turn around the wearer. false 1.0
radius Float Radius of the shell at full amount, in blocks. false 1.1
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type the grains are drawn with. false minecraft:entity_translucent

Sunstone Blade Render Layer

A blade of sunstone grains held in the wearer's hand, the same material as fsang:sunstone_cape. How much of it there is comes from "amount", a value meant to follow an ability's animation timer: at 0 nothing is drawn and as it rises the blade grows out of the fist. It moves with the hand and is drawn in first person too. It is purely visual.

Settings:

Setting Type Description Required Fallback Value
sparkle Float 0-1: the share of grains that catch the light as a bright glint. false 0.1
amount Float / Value (Dynamic) 0-1: how much of the blade is present. 0 draws nothing. false 0.0
length Float Length of the blade at full amount, in blocks. false 1.25
width Float Width of the blade at the fist, in blocks; it narrows to a point. false 0.16
left_hand Boolean Whether the blade is in the left hand instead of the right. false false
tint Color Multiplied onto the grains' color. false #FFFFFF
grain_size Vector 2D [smallest, largest] size of a grain, in blocks. false [0.025, 0.07]
grains Integer 0-1024: how many grains make up the blade. Fewer are drawn with distance. false 150

Examples:

{"type":"fsang:sunstone_blade","amount":1}

Sunstone Cape Render Layer

A cape made of Kryptonian sunstone dust. It takes every setting of argon:cloth (texture, size, segments, material, attach, wrap and the rest) and uses Argon's cloth simulation for all of its shape and motion, but draws it as a coherent surface that breaks into grains toward the hem and outer corners, with a small number of free grains that come loose, trail behind and sometimes rejoin. The breakup uses the cape's own coordinates, so it stays with the cape, and it grows with how fast the wearer moves and how hard the cape is bent.

Settings:

Setting Type Description Required Fallback Value
edge_fragmentation Float 0-4: how much more the hem and outer corners break up than the shoulders. false 1.0
sparkle Float 0-1: the share of grains that catch the light as a bright glint. false 0.06
reveal Float / Value (Dynamic) grows the cape in from the shoulders down and takes it back up again. 0 is no cape and reveal_ticks is the whole cape. Meant for an openable chestplate's palladium:item_open_timer, so the cape grows in as it opens and runs back as it closes. When the cape is fully gone the layer draws nothing. false 1.0
curvature_fragmentation Float 0-4: how much the parts of the cape that are bent hard shed extra. It is subtle by design. 0 turns it off. false 1.0
material_amount Float / Value (Dynamic) 0-1: how much of the cape's material is present. 1 is the full cape, lower leaves a sparser, more broken cape and sheds more dust, 0 is dispersed entirely. false 1.0
fragmentation Float Overall strength of the procedural breakup, 0-4. 0 is no breakup at all. false 1.0
segments Vector 2D As for argon:cloth: [segments_x, segments_y] of the physics grid. false [4, 8]
motion_fragmentation Float 0-4: how much moving (walking, sprinting, flying, turning) adds to the breakup. 0 makes it ignore movement. false 1.0
attachment "back" | "left_arm" | "right_arm" | "waist" As for argon:cloth. false back
reveal_ticks Float The reveal value that means fully revealed, and so the number of ticks the cape takes to grow in or out. Set it to the openable's time. false 1.0
recoalesce Float 0-1: the share of grains that drift back to where they came off and rejoin the cape instead of just fading. false 0.4
attach Vector 3D As for argon:cloth: [x, y, z] of the attach point from the neck. Y increases downward and a positive Z is behind the wearer; a smaller Z hangs closer to the back. false [0.0, 0.1, 0.4]
dust_tint Color Multiplied onto the grains' color, which they otherwise take from the cape texture where they came off. false #FFFFFF
pitch_influence Float As for argon:cloth (waist attachment only). false 0.6
dust_density Float 0-8: how many free grains come off. 0 turns them off. false 1.0
hem_pitch_fraction Float Unused, as for argon:cloth. false 0.25
solidity Float 0-1: how much of the cape stays one coherent surface. Higher is more like an ordinary cape, lower breaks up sooner. false 0.75
max_dust Integer 0-512: the most free grains one cape has at once. Fewer are used with distance. false 160
light_emission Integer / Value (Dynamic) 0-15: makes the cape and its grains glow. With one of Argon's glow render types (argon:glow_emission, argon:additive_emission) it is the brightness itself; with any other render type it is a light level they are lit to at least. 0 leaves the world light alone. false 0
texture Identifier | Dynamic Texture | Texture Reference The cape texture, exactly as for argon:cloth. Free grains take their color from it too. true /
shrink_player_parts string[] As for every pack render layer: player model parts to shrink while this layer renders. false []
dust_trail_strength Float 0-8: how far grains carry their speed and so trail behind the wearer. Higher trails further. false 1.0
grain_size Vector 2D [smallest, largest] size of a free grain, in blocks. Most are near the smallest. false [0.022, 0.075]
noise_speed Float 0-10: how fast the breakup pattern evolves. false 1.0
depth Float As for argon:cloth (waist attachment only). false /
material Identifier | Inline Material Object As for argon:cloth: a registered cloth material or an inline object. Setting "collision" to false lets the cape hang right against the back instead of staying outside the torso collision capsule. false argon:standard
size Vector 2D As for argon:cloth: [length, width] of the cape at rest, in blocks. false [1.8, 1.0]
detail Integer 1-8: surface cells per physics cell along each axis, so how fine the grains of the cape surface are. Higher is finer and costs more. It is reduced automatically with distance. false 4
dispersion Float / Value (Dynamic) 0-1: material taken away from the cape, so it has material_amount * (1 - dispersion). Meant to be driven by an ability's animation timer, e.g. to send the material off to a fsang:sunstone_barrier layer. false 0.0
wrap Float As for argon:cloth. false 0.0
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type the cape surface and its grains are drawn with. false minecraft:entity_translucent
dust_lifetime Float How long a free grain lasts, in seconds. false 0.7

Examples:

{"type":"fsang:sunstone_cape","texture":"example:textures/models/capes/sunstone_cape.png"}

Lightning Sparks

Renders lightning sparks around the entity.

Settings:

Setting Type Description Required Fallback Value
amount Integer The amount of sparks to spawn during each occurence. false 5
render_settings Laser Renderer Settings The render settings for the sparks. true /
model_parts String | String[] Model parts the sparks are limited to, like "right_arm" or "head". Each spark picks one of them and stays inside the box of that part, moving along with it. Nested parts can be written as a path like "body.cape". If none are specified, the sparks fill the whole hitbox of the entity. false /
frequency Float The frequency of the sparks. false 0.5

Examples:

{"type":"palladium:lightning_sparks","frequency":0.2,"amount":10,"render_settings":{"glow":"#0000ff","bloom":2,"size":2.0}}
{"type":"palladium:lightning_sparks","amount":4,"render_settings":{"glow":"#ffff00","bloom":2},"model_parts":["right_arm","left_arm"]}

Anchored Lightning Sparks

Like Palladium's Lightning Sparks, but sparks can be anchored to named body-part bones instead of spawning anywhere in the bounding box, using the same "anchors" as the Thrusters layer.

Settings:

Setting Type Description Required Fallback Value
amount Integer The amount of sparks to spawn during each occurence, per anchor (or once for the whole entity if "anchors" is empty). false 5
render_settings Laser Renderer Settings The render settings for the sparks. true /
offset Vector 3D [x, y, z] offset applied after positioning at the anchor (or the whole entity, if "anchors" is empty) - lets sparks sit slightly away from the bone's exact pivot instead of centered on it. false [0.0, 0.0, 0.0]
shrink_player_parts string[] Player model parts to shrink while this layer renders, as for every pack render layer. false []
anchors string[] Bones of the player model to spawn sparks at, e.g. "head", "right_arm" - each gets its own independent spark cycle. Empty (the default) spawns sparks randomly across the whole entity, matching palladium:lightning_sparks. false []
frequency Float The frequency of the sparks. false 0.5
anchor_size Float Only relevant when "anchors" isn't empty: how far, in blocks, sparks jitter from the anchor point. false 0.3

Examples:

{"type":"argon:anchored_lightning_sparks","frequency":0.2,"amount":10,"render_settings":{"glow":"#0000ff","bloom":2,"size":2.0},"anchors":["head","right_arm"],"anchor_size":0.25,"offset":[0.0,0.1,0.0]}

Cloth Render Layer

Renders a physically simulated cloth grid (a cape, by default) that flows, bends and trails behind the wearer instead of rotating as a rigid plane.

Settings:

Setting Type Description Required Fallback Value
taper Float Only meaningful for a "back" attachment: the width at the shoulders (the pinned edge) as a fraction of the full width at the hem, from 0.05 to 1. Below 1 the cloth is a trapezoid that is narrow at the shoulders and flares out to "width" at the hem, like a cape. 1 = a plain rectangle. false 1.0
aerodynamics { airflow_strength, turn_inertia, flight_stabilization, flight_stiffness_multiplier, stiffness_response, body_hug, hug_start, limb_collision, narrowing, flutter } How the cloth reacts to the wearer's real speed, not the selected flight level. Keys: airflow_strength (1), turn_inertia (1), flight_stabilization (0.6, calms swinging at speed), flight_stiffness_multiplier (1.15), stiffness_response (0.1) and body_hug (0.75, how tightly a back cape is pulled against the body near top speed) and hug_start (0.6, how far through the speed range the hugging begins). "narrowing" (not for "waist"): { enabled, start_fraction (0.25) and full_fraction (0.85) of the wearer's top flight speed, start_speed (10 blocks/s) and full_speed (40) when there is no flight, maximum (0.6; 0.35 when "wrap" is above 0 or for arms), compression (0.5, how much of the narrowing squeezes the cloth itself instead of folding it), response (0.06), recovery (0.04), distribution (1.5, higher keeps the top wider), fold (1, 0 turns the pleats off) }. "limb_collision" (back capes): { enabled (true), torso: { width (0.5), depth (0.25), length (1.1), radius (0.1) }, head: { width (0.5), depth (0.5), length (0.5), radius (0.1) }, arms: { radius (0.3), length (0.8) }, legs: { radius (0.25), length (0.8) } }, the shapes the cloth is kept out of. "flutter": { intensity (1), frequency (1), speed_influence (1), damping (0.6), edge_multiplier (1.5) }. false {}
texture Identifier | Dynamic Texture | Texture Reference The texture to render the cloth with. UVs are stable across the whole grid regardless of how the cloth deforms. true /
shrink_player_parts string[] Player model parts to shrink while this layer renders, as for every pack render layer. false []
segments Vector 2D [segments_x, segments_y]: simulation columns/rows. More = smoother bending at a performance cost. false [4, 8]
depth Float Waist attachment only: half-depth of the box's front and back sides, in blocks. Usually smaller than "width", since players are thinner front to back. Defaults to "width". false /
attachment "back" | "left_arm" | "right_arm" | "waist" Which part of the cloth grid is pinned to the wearer: "back" (cape), "left_arm" or "right_arm" (draped along an arm), or "waist" (skirt or kilt, a box-shaped loop around the hips). false back
material Identifier | Inline Material Object A registered material id (e.g. "argon:heavy") or an inline object overriding individual physics properties. false argon:standard
size Vector 2D [length, width] of the cloth at rest, in blocks. For a "waist" attachment, "width" is instead the HALF-WIDTH of its box cross-section's left/right sides (not a flat width) - see "depth" for the front/back sides. false [1.8, 1.0]
attach Vector 3D [x, y, z] offset of the attach point from the neck, in wearer space: Y=0 is neck height and increasing Y moves DOWN; a cape needs a positive Z to sit behind. For "waist", use X=0, Z=0 and Y about 0.75-0.9. false [0.0, 0.1, 0.4]
wrap Float Only meaningful for a "back" attachment: curves the pinned edge's rest shape forward so it hugs the wearer's sides, turning a flat cape into a wrap-around cloak. 0 = flat. false 0.0
pitch_influence Float Waist attachment only: while crouching, the garment follows the body's pitch as one rigid piece. This scales how much, from 0 (ignored) to 1 (fully). false 0.6
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type to draw the cloth with. false minecraft:entity_translucent
hem_pitch_fraction Float Currently unused - kept only so existing configs that set it don't fail to load. false 0.25

Examples:

{"type":"argon:cloth","texture":"example:textures/models/capes/red_cape.png"}
{"type":"argon:cloth","material":"argon:heavy","size":[2.4,1.6],"segments":[5,10],"wrap":0.6,"texture":"example:textures/models/cloaks/heavy_cloak.png"}
{"type":"argon:cloth","attachment":"left_arm","material":"argon:lightweight","size":[1.2,0.5],"segments":[3,6],"attach":[-0.3,0.2,0.0],"texture":"example:textures/models/arm_cloth.png"}
{"type":"argon:cloth","attachment":"waist","material":"argon:leather","size":[0.32,0.28],"segments":[16,6],"depth":0.1599999964237213,"pitch_influence":0.5,"attach":[0.0,0.64,0.0],"texture":"example:textures/models/skirts/skirt.png"}

Fade Render Layer

Wraps another render layer and draws it at a changing opacity so it can fade in and out. Put the wrapped layer's conditions inside "layer". Nothing is drawn at opacity 0.

Settings:

Setting Type Description Required Fallback Value
opacity Float / Value (Dynamic) 0-1: how opaque the wrapped layer is drawn. Typically the eased animation timer of an ability, e.g. palladium.get_animation_timer_eased('namespace:power#ability'), which already runs 0 to 1. false 1.0
layer Render Layer The render layer to draw, written exactly as it would be on its own, including its "conditions". true /

Examples:

{"type":"argon:fade","opacity":{"type":"palladium:molang_float","molang":"palladium.get_animation_timer_eased('example:power#some_ability')"},"layer":{"texture":{"type":"palladium:eye_selection","color":"#6b6b6b"}}}
