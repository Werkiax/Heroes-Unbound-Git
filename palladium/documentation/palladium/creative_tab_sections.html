Animated Textured

A creative tab section with an animated, multi-frame texture banner.

Settings:

Setting Type Description Required Fallback Value
vertical_size Integer Height of a single frame. false /
frames Integer Number of vertically stacked frames in the texture. false /
texture Identifier Texture used for the banner. Defaults to a texture derived from the id. false /
texture_offset_x Integer Horizontal offset at which the texture is rendered. false /
texture_offset_y Integer Vertical offset at which the texture is rendered. false /
text_outline Color Outline color of the title text. false /
text_shadow Boolean Whether the title text is rendered with a shadow. false /
id Identifier Unique identifier of the section. true /
text_color Color Color of the title text. false /
horizontal_size Integer Width of a single frame. false /
items Item ID or variant group array Items and/or multiversal variant groups displayed in this section. false /
frame_time Float Duration of each frame in milliseconds. false /

Examples:

{"type":"fancytabsections:animated_textured","id":"palladium:example"}

Colored

A creative tab section with a flat colored banner.

Settings:

Setting Type Description Required Fallback Value
banner_color Color Color of the banner background. false /
text_outline Color Outline color of the title text. false /
text_shadow Boolean Whether the title text is rendered with a shadow. false /
id Identifier Unique identifier of the section. true /
text_color Color Color of the title text. false /
items Item ID or variant group array Items and/or multiversal variant groups displayed in this section. false /

Examples:

{"type":"fancytabsections:colored","id":"palladium:example","text_shadow":true}
