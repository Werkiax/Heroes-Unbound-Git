Empty

Empty background. Renders nothing

Random Tiles

Fills the background with a random mix of tiles, like a floor of different blocks. It starts with the base texture everywhere, then every layer scatters patches of its own texture over it, in the order they are listed. The pattern is always the same for the same seed.

Settings:

Setting Type Description Required Fallback Value
seed Integer The seed of the random pattern. false 0
layers Layer[] Textures scattered over the base tile, in list order. false []
tile_size Integer (> 0) The size of a tile in pixels. false 16
base Texture Reference | Dynamic Texture The texture that fills every tile at first. Either a texture, or an object with 'texture' and 'random_rotation'. true /

layers[] (Layer)

Setting Type Description Required Fallback Value
texture Texture Reference | Dynamic Texture The texture used for this layer. true /
random_rotation Boolean Whether to rotate the texture randomly. false false
chance Number (0.0 ~ 1.0) The chance for each tile to start a patch. true /
size Integer (> 0) | Object How many tiles a patch covers, as a positive integer or an integer provider. Use 1 for single tiles. false 1

Examples:

{"type":"palladium:random_tiles","base":{"texture":"minecraft:textures/block/dirt.png","random_rotation":true},"layers":[{"texture":"minecraft:textures/block/coarse_dirt.png","random_rotation":true,"chance":0.03,"size":{"min_inclusive":3,"max_inclusive":8,"type":"minecraft:uniform"}},{"texture":"minecraft:textures/block/gravel.png","chance":0.02}]}

Repeating Texture

Repeating a texture so often that it fills the background.

Settings:

Setting Type Description Required Fallback Value
texture Texture Reference | Dynamic Texture Texture path. true /
width Integer (>= 0) Width of the texture file. false 256
height Integer (>= 0) Height of the texture file. false 256

Sprite

Renders a sprite accordingly to fill the background.

Settings:

Setting Type Description Required Fallback Value
sprite Identifier Sprite ID. true /

Texture

Renders a static texture as a background.

Settings:

Setting Type Description Required Fallback Value
texture Texture Reference | Dynamic Texture Texture path. true /
width Integer (>= 0) Width of the texture file. false 256
height Integer (>= 0) Height of the texture file. false 256
