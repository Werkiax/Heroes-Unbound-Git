Argon

Blit

Renders a simple (piece of a) texture

Settings:

Setting Type Description Required Fallback Value
u Integer / Value U-position on the texture where to start drawing from false 0
texture Texture Reference | Dynamic Texture Texture path/dynamic texture true /
v Integer / Value V-position on the texture where to start drawing from false 0
rotation Float / Value Rotation in degrees, applied around the center of the widget false 0.0
scale Float / Value Scale multiplier, applied around the center of the widget. Only affects rendering, the widget keeps its original bounds false 1.0
texture_height Integer / Value Total height of the texture file false 256
opacity Float / Value Opacity between 0 (invisible) and 1 (fully opaque) false 1.0
properties UI Properties Properties of this widget false {"width":50,"height":18}
texture_width Integer / Value Total width of the texture file false 256

Examples:

{"type":"palladium:blit","texture":"mypack:textures/gui/texture_file.png"}

Button

Adds a button.

Settings:

Setting Type Description Required Fallback Value
close_on_press Boolean Whether or not the screen will be closed when pressing the button. This also closes the screens it was opened from. Combined with "palladium:open_screen", the new screen replaces this one. false false
action Dialog Action Action that is run when the button is pressed, in the vanilla dialog action format. "palladium:open_screen" opens the new screen right away, pressing Escape there returns to this screen. false /
text Text Component Text of the button true /
properties UI Properties Properties of this widget false {"width":50,"height":18}

Examples:

{"type":"palladium:button","text":"Click me!","close_on_press":true}
{"type":"palladium:button","text":"Next page","action":{"type":"palladium:open_screen","screen":"mypack:next_page"}}

Player Display

Settings:

Setting Type Description Required Fallback Value

rotation Vector 3D The rotation that is applied to the player. If 'follow_mouse' is active, the rotation will be ignored. false /
scale Float (>= 0.0) Scale of the player. false 30.0
properties UI Properties Properties of this widget false {"width":50,"height":18}
apply_customization_category_preview Customization Category ID(s) ID(s) of customization category that should be previewed false /
mimic_player Boolean When enabled the player will copy all of the actual player's properties. Equipment, animation, render layers, etc. false true
render_layers Identifier | Identifier[] List of/single render layer ID that will be attached to the rendered player. false /

{"type":"palladium:player_display"}

Progress Bar

Renders a progress bar, where the filled texture is cut off according to the current value.

Settings:

Setting Type Description Required Fallback Value
filled_texture Texture Reference | Dynamic Texture Texture path/dynamic texture for the filled part of the bar. true /
u Integer / Value U-position on the textures where to start drawing from false 0
background_texture Texture Reference | Dynamic Texture Texture path/dynamic texture drawn behind the filled part. If not set, only the filled part is drawn. false /
v Integer / Value V-position on the textures where to start drawing from false 0
texture_height Integer / Value Total height of the texture files false 256
opacity Float / Value Opacity between 0 (invisible) and 1 (fully opaque) false 1.0
value Integer / Value The current value of the bar. true /
properties UI Properties Properties of this widget false {"width":50,"height":18}
texture_width Integer / Value Total width of the texture files false 256
max_value Integer / Value The value at which the bar is full. Values of 0 or less leave the bar empty. true /
direction "left_to_right" | "right_to_left" | "bottom_to_top" | "top_to_bottom" The direction in which the bar fills up. false left_to_right

Examples:

{"type":"palladium:progress_bar","value":0,"max_value":100,"background_texture":"mypack:textures/gui/progress_bar_background.png","filled_texture":"mypack:textures/gui/progress_bar_filled.png"}
