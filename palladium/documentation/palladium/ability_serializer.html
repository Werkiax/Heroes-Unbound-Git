Mode Switch

Switches between a map of modes. By default it cycles to the next mode whose conditions are met each time it is activated. With the menu selection, holding the ability's key opens a row of all available modes next to the ability in the ability bar instead. Scroll to pick one, then let go of the key (or click, see "confirm") to switch to it. The menu works with every key behaviour, but "held" is recommended, since the ability then also counts as enabled while the menu is open.

Settings:

Setting Type Description Required Fallback Value
confirm "release" | "left_click" | "right_click" Only used by the menu. "release" switches to the picked mode when the key is let go. "left_click" and "right_click" switch when clicking while the menu is open, and letting go of the key without clicking closes the menu without changing anything. false RELEASE
modes Anything A map of mode key -> mode (at least one). Each mode has a required "title", an optional "icon" texture, and optional "conditions" (a mode is only switchable-to while its conditions are met, and it is hidden from the menu otherwise). "on_selected" and "on_unselected" are optional actions, run on the server when the mode becomes the active one or stops being it. They only run on an actual change, so the first mode, which is active from the start, doesn't run "on_selected" until it is switched back to. The key is the unique id used by the mode condition and value. true /
selection "cycle" | "menu" How a mode is picked. "cycle" switches to the next mode on every activation, "menu" opens a selection menu while the key is held. The menu needs a key that can be held, so it does not work with scroll or GUI button key binds. false CYCLE
show_popup Boolean If the new mode is briefly shown in the middle of the screen after switching. false true

Examples:

{"type":"palladium:mode_switch","modes":{"mode_a":{"title":"Mode A"}}}
{"type":"palladium:mode_switch","modes":{"mode_a":{"title":"Mode A"},"mode_b":{"title":"Mode B"}},"selection":"menu","show_popup":false}
