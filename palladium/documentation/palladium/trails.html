After Image Trail

Renders copies of the entity behind it.

Settings:

Setting Type Description Required Fallback Value
color Color Defines the color/tint of the after image false #ffffff
blur_layers Integer Amount of times each after image is rendered on top of itself, each layer slightly scaled up, to create a blurry outline false 1
flat_color Boolean If enabled, the after image is rendered as a flat, fullbright silhouette in the given color instead of a tinted copy of the entity's textures false false
edges Boolean If enabled, only high-contrast edges of the entity's textures are rendered as fullbright lines in the given color, the rest is mostly transparent false false
blur_scale Float How much each additional blur layer is scaled up false 0.05
opacity Float Starting opacity of the after image false 0.5

Examples:

{"type":"palladium:after_image","color":"#ff0000","opacity":0.2}
{"type":"palladium:after_image","opacity":0.3,"flat_color":true,"edges":true,"blur_layers":3}

Gradient Trail

Renders a colored gradient behind the players.

Settings:

Setting Type Description Required Fallback Value
orientation "horizontal" | "vertical" Defines the orientation in relation to the entity in which the gradient will render false VERTICAL
color Color Defines the color of the gradient false #ffffff
offset Float Defines where the gradient will start in relation to entity hitbox. 0.5 is equal to the center. false 0.5
opacity Float Starting opacity of the gradient false 0.5

Examples:

{"type":"palladium:gradient","color":"#ff0000","opacity":0.7,"orientation":"horizontal","offset":0.2}

Lightning Trail

Renders lightning behind the entity.

Settings:

Setting Type Description Required Fallback Value
area Vector 3D Box (in blocks) the lightning spreads within. Scales with the size of the entity. Defaults to the entity hitbox. false [0.6, 1.8, 0.6]
amount Integer Defines how many lightnings will follow the player false 10
render_settings Laser Renderer Settings The render settings for the lightning. true /

Examples:

{"type":"palladium:lightning","amount":7,"render_settings":{"glow":"#0000ff","size":2.0}}

Lightning Aura Trail

Renders independently growing lightning arcs with branches around an entity (inspired by DCEU Flash).

Settings:

Setting Type Description Required Fallback Value
amount Integer Arcs created per timer event false 1
render_settings Laser Renderer Settings The render settings for the arcs. true /
arc_settings Anything Arc range, branch timing, jitter, and block-target search settings. Ranges, distances and jitter scale with the size of the entity. false ArcSettings[idleRange=4.5, runningRange=8.0, sprintingRange=11.0, sideRangeMultiplier=0.7, rearRangeMultiplier=1.2, branchStartMin=0.22, branchStartMax=0.6, branchDelayMin=0.08, branchDelayMax=0.3, jitterAmount=0.055, jitterSpeed=0.27, searchDirections=64, minimumTargetDistance=0.75]
growth Integer Ticks required for an arc to fully grow false 3
branches Integer Branches created for each arc false 2
segments Integer Segments in each arc false 5

Examples:

{"type":"palladium:lightning_aura","branches":1,"render_settings":{"glow":{"color":"#ff7a1a","opacity":0.75}}}
{"type":"palladium:lightning_aura","amount":2,"branches":3,"segments":8,"growth":4,"render_settings":{"glow":{"color":"#00aaff","opacity":0.8,"rainbow":0.5,"pulse":{"scale":0.25,"frequency":2.0}},"core":{"pulse":{"scale":0.1}},"bloom":3,"size":2.0,"rotation_speed":4.0},"arc_settings":{"search_directions":48}}

Motion Blur Trail

A short, translucent, tapering ribbon built from the entity's recent positions that reads as a motion blur, with optional thin secondary streaks and surface dust. It follows the entity's actual speed: nothing is drawn below minimum_trail_speed, and length, opacity and width grow smoothly towards maximum_trail_speed. Use with tick_delay 1 and a lifetime of at least max_age.

Settings:

Setting Type Description Required Fallback Value
lod Distance Settings Distance quality: beyond far_distance only a simplified ribbon is drawn, beyond cull_distance nothing. false /
streaks Streak Settings Thin secondary streaks beside the ribbon: enabled, count, width, lifetime (ticks), opacity, color. false /
trail_taper_curve Float Exponent of the taper. 1 is linear, higher keeps the ribbon wide for longer before narrowing. false 1.4
trail_height Float Height in blocks of the vertical sheet crossing the ribbon. 0 draws only the flat sheet. false 1.4
color Color Main colour of the blur. false #648aa3
texture Texture Reference Texture drawn along the ribbon. The first axis runs from the entity to the tail, the second across the ribbon, with the soft centre in the middle. false argon:textures/trail/motion_blur.png
edge_color Color Colour of the faint outer boundary. false #3b6687
highlight_color Color Colour the centre moves towards at high speed. false #d6e4ea
speed Speed Settings How the effect reacts to actual movement speed (blocks per second): minimum_trail_speed, maximum_trail_speed, intensity_curve, length_multiplier, opacity_multiplier, width_multiplier, acceleration_response (0-1 share per tick), deceleration_fade (ticks). false /
trail_start_width Float Ribbon width in blocks next to the entity. false 0.6
trail_end_width Float Ribbon width in blocks at the oldest end. false 0.08
max_age Float Ticks a ribbon segment stays visible at full intensity. false 6.0
smoothing Float How strongly the ribbon curves between recorded positions. 0 gives straight lines with sharp corners. false 0.4
opacity Float Opacity at full intensity, before the speed opacity multiplier. false 0.55
glow Boolean If true, the ribbon is drawn additively and unaffected by world light. false false
dust Dust Settings Block particles kicked up from the ground while running: enabled, max_per_tick, lifetime (ticks), range (blocks from the camera), turn_burst, splash. false /

Examples:

{"type":"argon:motion_blur"}
