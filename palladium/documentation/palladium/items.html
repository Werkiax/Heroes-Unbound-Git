Upgrade Template

A smithing template item that applies a Palladium item_upgrade to another item.

Settings:

Setting Type Description Required Fallback Value
upgrade Identifier The item_upgrade this smithing template applies. true /
applies_to Identifier Item tag restricting which items can be used in the smithing table's base slot. false /
properties Anything Vanilla and Palladium item properties. true /

Examples:

{"type":"palladium:upgrade_template","upgrade":"examplemod:my_upgrade","applies_to":"minecraft:swords"}

Energy Item

An item that stores RF/FE energy through NeoForge's transfer API (any RF compatible block or item can charge or drain it), or infinite energy with the "argon:creative_energy" data component.

Settings:

Setting Type Description Required Fallback Value
max_insert Integer (> 0) The maximum amount of energy that can be inserted per operation. Defaults to "capacity". false /
max_extract Integer (> 0) The maximum amount of energy that can be extracted per operation. Defaults to "max_insert". false /
properties Anything Vanilla and Palladium item properties. true /
capacity Integer (> 0) The maximum amount of energy the item can store. false 10000

Examples:

{"type":"argon:energy_item","capacity":20000,"max_insert":500,"max_extract":500}
{"type":"argon:energy_item","capacity":20000,"properties":{"components":{"argon:creative_energy":{}}}}

Mace

A mace-behaving item with configurable smash-attack behavior.

Settings:

Setting Type Description Required Fallback Value
heavy_smash_threshold Float Fall distance required for a heavy smash attack. false 5.0
allow_smash_while_fall_flying Boolean Whether smash attacks can trigger while elytra flying. false false
smash_damage_multiplier Float Multiplier applied to smash-attack bonus damage. false 1.0
smash_fall_threshold Float Minimum fall distance required for a smash attack to trigger. false 1.5
smash_knockback_radius Float Radius of the knockback wave on smash attacks. false 3.5
smash_knockback_multiplier Float Multiplier applied to smash-attack knockback. false 1.0
reset_fall_distance Boolean Whether fall distance resets after a smash attack. false true
density_level Integer Density enchantment level baked into the item, adding fall-distance-based bonus damage. false 0
wind_burst_level Integer Wind Burst enchantment level baked into the item. false 0
heavy_knockback_amount Float Extra knockback levels applied on a heavy smash. false 2.0
properties Anything Vanilla and Palladium item properties. true /

Examples:

{"type":"minecraft:mace","smash_fall_threshold":1.5,"heavy_smash_threshold":5.0}
