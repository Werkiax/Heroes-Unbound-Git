Texture Transformers

Overview

Palladium

  • Alpha Mask
  • Overlay

Alpha Mask

Makes parts of the base image see-through based on the brightness of the mask image. Black mask pixels keep the base fully visible, white pixels hide it completely, grays fade it partially and fully transparent mask pixels hide it as well. The mask is read pixel by pixel at the same coordinates as the base, so it should have the same size as the base texture. A set of masks with a growing white area, combined with a variable, gives a dissolve or build-up effect.

Settings:

Setting Type Description Required Fallback Value
mask Identifier The location of the mask texture. Can use variables. true /

Examples:

{"type":"palladium:alpha_mask","mask":"example:mask"}

Overlay

Draws a second image on top of the base image, respecting its transparency, like stacking two layers in an image editor. The overlay is read pixel by pixel at the same coordinates as the base, so it should have the same size as the base texture.

Settings:

Setting Type Description Required Fallback Value
overlay Identifier The location of the overlay texture. Can use variables. true /
ignore_blank Boolean If true, the overlay is only applied where the base already has pixels, so it can never add pixels outside the existing shape. false false

Examples:

{"type":"palladium:overlay","overlay":"example:mask"}

Tint

Multiplies the colors of the base image with a color, keeping its transparency, so one grayscale or neutral texture can be recolored. Both settings can use variables, which makes the color and strength follow a data attachment. Note that variable values also end up in the generated texture's path, so a color variable should be lowercase hex without a leading #, and a strength variable should take only a few different values (for example integer percentages mapped in a Value), because every distinct value creates its own texture.

Settings:

Setting Type Description Required Fallback Value
color String The tint color as hex, like "ffd24a" or "#ffd24a". Can use variables. true /
opacity String How strongly the tint is applied, from 0 (no change) to 1 (full tint). Can use variables. false 1

Examples:

{"type":"palladium:tint","color":"ffd24a"}
