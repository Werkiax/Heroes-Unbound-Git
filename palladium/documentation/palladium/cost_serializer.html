Experience Level Cost

Requires the entity to have a certain number of experience levels.

Settings:

Setting Type Description Required Fallback Value
xp_level Integer (> 0) The number of experience levels to consume. true /

Examples:

{"type":"palladium:experience_level","xp_level":5}

Item Cost

Requires the entity to have a certain item in their inventory.

Settings:

Setting Type Description Required Fallback Value
amount Integer (> 0) How many items to consume. false 1
ingredient Ingredient / Item The item(s) accepted as payment. true /

Examples:

{"type":"palladium:item","ingredient":"minecraft:diamond","amount":5}

Effect Cost

Requires a mob/potion effect of a certain rank/amplifier, which is consumed/reduced by the amount.

Settings:

Setting Type Description Required Fallback Value
amount Integer (> 0) How many levels/amplifier of the effect to consume. false 1
effect Mob Effect ID The type of effect required true /

Examples:

{"type":"palladium:mob_effect","effect":"minecraft:hero_of_the_village"}

Multiversal Designation Cost

Requires items that carry a designation of a specific universe, like a Multiversal Extrapolator that has found that universe. The items are consumed.

Settings:

Setting Type Description Required Fallback Value
amount Integer (> 0) How many designated items to consume. false 1
universe Universe ID The universe the items must be designated to. true /

Examples:

{"type":"palladium:multiversal_designation","universe":"example:earth_616"}

Number Data Attachment Cost

Requires the entity to have a certain value in a number data attachment, which is consumed.

Settings:

Setting Type Description Required Fallback Value
amount Integer (> 0) The amount consumed from the data attachment. false 1
attachment Data Attachment ID The ID of the data attachment. true /
icon Icon definition The icon shown in the UI. true /
description Text Component / Value The display text shown in the UI. true /

Examples:

{"type":"palladium:number_data_attachment","attachment":"example:number_attachment_id","amount":10,"icon":{"type":"palladium:sprite","sprite":"example:sprite_path"},"description":"My Currency"}

Score Cost

Requires the entity to have a certain scoreboard score.

Settings:

Setting Type Description Required Fallback Value
amount Integer (> 0) The score amount to consume. false 1
icon Icon definition The icon shown in the UI. true /
description Text Component / Value The display text shown in the UI. true /
objective String The scoreboard objective name. true /

Examples:

{"type":"palladium:score","objective":"my_score","amount":10,"icon":{"type":"palladium:sprite","sprite":"example:sprite_path"},"description":"My Score"}
