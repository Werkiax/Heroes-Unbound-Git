Buyable

The ability starts out locked. The player can click it in the power screen and pay the cost to unlock it for good.

Settings:

Setting Type Description Required Fallback Value
cost Cost What the player has to pay to unlock the ability. It gets taken away once the ability is bought. true /
requires Condition | Condition[] Additional condition(s) that need to be fulfilled. Even after the ability was bought, it is only unlocked while these are fulfilled. Like with the conditional handler, an 'Ability unlocked' condition in here will show up as the parent in the power tree. false /

Examples:

{"type":"palladium:buyable","cost":{"type":"palladium:experience_level","xp_level":5}}
{"type":"palladium:buyable","cost":{"type":"palladium:item","ingredient":"minecraft:diamond","amount":3},"requires":{"type":"palladium:ability_unlocked","ability":"example:power#ability_key"}}

Conditional

Unlocks the ability for as long as the given conditions are fulfilled. You can also skip the handler object and just put the condition(s) straight into the 'unlocking' field, it does the same thing.

Settings:

Setting Type Description Required Fallback Value
conditions Condition | Condition[] The condition(s) that need to be fulfilled for the ability to be unlocked. If one of them is an 'Ability unlocked' condition, the referenced ability will show up as its parent in the power tree. true /

Examples:

{"type":"palladium:conditional","conditions":{"type":"palladium:crouching"}}
{"type":"palladium:conditional","conditions":{"type":"palladium:ability_unlocked","ability":"example:power#ability_key"}}

Buyables

Like the buyable handler, but the listed abilities must all be unlocked before it can be bought, and each can optionally be left out of the power tree's connection lines.

Settings:

Setting Type Description Required Fallback Value
cost Cost What the player has to pay to unlock the ability. true /
requires Requirement[] Abilities that have to be unlocked first. Each entry has an "ability" reference and an optional "draw_line" flag. false []
