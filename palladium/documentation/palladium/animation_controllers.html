Animation Controllers

Overview

Palladium

  • Default
  • Triggered

Default

State machine: every state plays an animation and lists conditions that move the controller into other states. Used when no "type" is given.

Settings:

Setting Type Description Required Fallback Value
blend_transition Integer | Time String ("40s", "2m", etc.) Ticks to blend when switching animations. 0 switches instantly. false 5
parent Identifier Another animation controller of the same type to inherit from. Own values override the parent's. false /
initial_state String State the controller starts in. false /
animations Map Named animation shortcuts, referenced as "#name". A list picks a random entry each time. false /
states Map States of this controller, keyed by name. Transitions are evaluated in order every tick. false /

Triggered

Plays one-shot animations when a condition becomes true. Each trigger plays its animation once, then waits until its condition is false again before it can fire again. No states or transitions needed.

Settings:

Setting Type Description Required Fallback Value
blend_transition Integer | Time String ("40s", "2m", etc.) Ticks to blend when switching animations. 0 switches instantly. false 5
parent Identifier Another animation controller of the same type to inherit from. Own values override the parent's. false /
animations Map Named animation shortcuts, referenced as "#name". A list picks a random entry each time. false /
triggers Map Animations to play, keyed by animation ID or "#key" reference, with the condition that triggers them. Earlier entries win when several conditions are true at once. false /
