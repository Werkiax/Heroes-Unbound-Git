Flat Textured

Renders a beam between two points as a flat texture that always faces the camera. The texture is repeated along the beam and never stretched; the last repetition is cut off if the remaining length is shorter than one tile.

Settings:

Setting Type Description Required Fallback Value
light_emission Integer The light emission of the beam. Must be within 0 - 15 false 0
texture Texture Reference | Dynamic Texture The texture to use for the beam. true /
texture_size Float The size of one texture tile: width of the beam and length of one repetition along it. false 1.0
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type to render the beam with. false minecraft:entity_translucent

Examples:

{"type":"palladium:flat_textured","texture":"namespace:textures/beams/example_beam.png","texture_size":2.0}

Lightning Beam

Renders a fluctuating lightning between two points.

Settings:

Setting Type Description Required Fallback Value
render_settings Laser Renderer Settings The render settings for the lightning. true /
segments Integer The amount of segments the lightning should have. false 5
frequency Integer The frequency of the lightning fluctuation. false 2
spread Float The spread of the lightning fluctuation. It defines how "far" the lightning can spread out from the core false 5.0

Examples:

{"type":"palladium:lightning","render_settings":{"glow":"#0000ff","bloom":2,"size":2.0},"segments":10,"frequency":4,"spread":112.0}

Boxed Textured

Renders a beam as a stack of textured boxes like palladium's "textured" renderer, but each face has its own lighting normal. That fixes wrong or flickering brightness on side and bottom faces.

Settings:

Setting Type Description Required Fallback Value
light_emission Integer The light emission of the beam, from 0 to 15. false 0
size Number or [width, height] The cross-section size of each box segment, in blocks. false 0.0625
texture Texture Reference The texture applied to each box segment. true /
rotation Float A fixed rotation, in degrees, around the beam's own axis. false 0.0
texture_length Float How many blocks of beam one full copy of the texture covers, separate from "size". Keeps the arm's thickness fixed while you control how dense the texture is. Defaults to the average of "size"'s width and height. false /
rotation_speed Float Degrees per tick to continuously spin the boxes around the beam's own axis. false 0.0
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type to render the beam with. false minecraft:entity_cutout

Examples:

{"type":"argon:boxed_textured","texture":"namespace:textures/beams/example_beam.png","size":3.0}

Cone

Draws a beam as a cone from "start_size" to "end_size" blocks wide, with a soft glow, a brighter core and an optional scrolling texture. Pair it with the "cone" setting of argon:energy_beam.

Settings:

Setting Type Description Required Fallback Value
core { color, opacity, scale } The brighter core inside the glow, set the same way. false { "color": "#FFFFFF", "opacity": 0.5, "scale": 0.45 }
end_fade Float How opaque the far end of the cone is compared to the start, 0 to 1. Lower fades the cone out along its length. false 0.2
start_size Float How wide the cone is where it starts, in blocks. false 0.15
glow_layers Integer How many nested cones the glow is made of (1-8): more is softer and thicker toward the middle. false 3
texture { texture*, color, opacity, scale, texture_length, around, scroll_speed, rotation_speed } A texture over the cone's surface. Keys: texture*, color, opacity (0.6), scale (1), texture_length (2), around (2), scroll_speed (0.03), rotation_speed (0). false /
blend "additive" | "translucent" How the cone is blended into the scene: additive glows brighter where layers overlap, translucent is a plain see-through surface. false ADDITIVE
end_distance Float If set, "end_size" is reached this many blocks from the start and the cone keeps that angle however long the beam is, so a beam stopped by a wall is narrower. Set it to the ability's max_distance. Without it, "end_size" is the width wherever the beam ends. false /
end_size Float How wide the cone is where it ends, in blocks. false 3.0
glow { color, opacity, scale } The soft outer glow: its colour (hex), its opacity (0 turns it off) and its width compared with the whole cone's. Drawn as "glow_layers" nested cones. false { "color": "#FFFFFF", "opacity": 0.35, "scale": 1.0 }
segments Integer How many flat sides the cone is drawn with (6-64): more is rounder. false 16

Examples:

{"type":"argon:cone","end_distance":20.0}

Glow Laser

Palladium's laser beam with brightness settings for its glow and core. Below 1 fades the part, above 1 stacks extra draws for a stronger glow (up to 8). Both are values, so molang can animate them.

Settings:

Setting Type Description Required Fallback Value
render_settings Laser Renderer Settings The render settings for the laser, exactly as for palladium:laser. true /
core_intensity (Dynamic) Value How bright the core is. 1 is the laser as Palladium draws it. false 1
glow_intensity (Dynamic) Value How bright the glow is. 1 is the laser as Palladium draws it. false 1

Examples:

{"type":"argon:glow_laser","render_settings":{"bloom":0},"glow_intensity":2,"core_intensity":1}

Ring

Draws a flat textured disc around the start of the beam, as wide as the beam is long, with bands that travel outward like shockwave rings. Only the beam's length matters, so it suits argon:anchored_beam, whose animation_timer fades it in and out.

Settings:

Setting Type Description Required Fallback Value
color Color A color multiplied with the texture. false #FFFFFF
texture Identifier The ring texture. Its U axis runs around the ring and its V axis outward. true /
blend "additive" | "translucent" How the ring is blended into the scene. false TRANSLUCENT
around Integer How many times the texture repeats around the ring. false 3
rotation_speed Float How many degrees per tick the ring spins. false 0.0
inner_radius Float Radius of the empty hole in the middle, in blocks. false 0.3
segments Integer How many flat sides the ring is drawn with (8-96). false 48
scroll_speed Float How many texture repeats the bands travel outward per tick; negative pulls them inward. false 0.25
end_fade Float How opaque the outer edge is compared with the inner one, 0 to 1. false 0.0
opacity Float How opaque the ring is, 0 to 1. false 0.8
texture_length Float How many blocks outward one repeat of the texture covers. false 4.0
twist Float How many degrees the ring is twisted between its inner and outer edge, which curves the bands into spirals. false 0.0
height Float How far above the start of the beam the ring is drawn, in blocks. false 0.05

Examples:

{"type":"argon:ring","texture":"example:textures/beams/ring.png"}

Segmented Textured

Renders a beam as flat textured layers around one axis that can tile, spin and scroll. Can sag near the origin and tighten over "sag_duration". Good for drill or corkscrew beams.

Settings:

Setting Type Description Required Fallback Value
sag_duration Integer | Time String ("40s", "2m", etc.) Ticks for the beam to go from loose to taut after it starts being drawn for an entity. It starts loose again after a fresh attach (e.g. a new swing or grapple). Only matters when "sag_amplitude" is above 0. false 10
light_emission Integer The light emission of the beam, from 0 to 15. false 0
textures Texture Layer (texture, size, spacing, rotation, rotation_speed, motion_speed, facing, pulse)[] The texture layers to render simultaneously around the beam axis, each either a sweeping ribbon ("facing": "radial", default) or a stack of flat cards facing down the beam ("along_beam"). true /
sag_waves Float How many full side-to-side wave cycles the sag has along the beam, fading from full strength at the origin to none at the target. Only matters when "sag_amplitude" is above 0. false 2.0
tint Item Tint (slot, source) Tints every texture layer by the color a registered source reads off an item in "slot" (first match wins). "source" is an id an addon registered; with no match it stays white. Omit for no tint. false /
render_type "minecraft:entity_translucent" | "minecraft:entity_cutout" | "palladium:glow" | "argon:glow" | "argon:additive" | "argon:glow_no_depth_write" | "argon:glow_emission" | "argon:additive_emission" The render type to render the beam with. false minecraft:entity_translucent
sag_amplitude Float How far, in blocks, the beam bows sideways from a straight line when loose, at its most bowed point near the origin. Both ends always stay pinned to their anchors. 0 (default) keeps the beam perfectly straight. false 0.0

Examples:

{"type":"argon:segmented_textured","textures":[{"texture":"namespace:textures/beams/example_beam.png","size":2.0,"spacing":1.0,"rotation_speed":20.0,"pulse":{"scale":0.1,"frequency":2.0}},{"texture":"namespace:textures/beams/example_beam.png","size":2.0,"spacing":4.0,"rotation_speed":10.0,"motion_speed":8.0,"facing":"along_beam"}],"sag_amplitude":0.35}
