Configured Texture

The texture type used when no type is given. With only variables it swaps between existing texture files, with transformers it builds a new texture in memory from the base image.

Settings:

Setting Type Description Required Fallback Value
output Identifier Path the generated texture is registered under. Supports variables. If not specified, it is derived from the base path, the used variables and the transformers. false /
variables Map A map of variables that can be used in the texture path. false /
transformers Texture Transformer | Texture Transformer[] Texture transformers applied to the base image, in the order they are listed. false /
base Identifier The base texture, as a full texture path including "textures/" and ".png". Can use variables. true /

Entity Texture

Starts from the texture the entity is currently rendered with. For players that is their skin, including skins set by abilities or customizations. On its own it is rarely useful; it exists to run transformers on the skin, for example to paint a suit pattern onto it.

Settings:

Setting Type Description Required Fallback Value
output Identifier Path the generated texture is registered under. Supports variables. If not specified, it is derived from the entity texture path, the used variables and the transformers. false /
variables Map A map of variables that can be used in the output path and transformer paths. false /
transformers Texture Transformer | Texture Transformer[] Texture transformers applied to the entity texture, in the order they are listed. false /

Examples:

{"type":"palladium:entity"}

Eye Selection Texture

Draws the pixels the player picked in the eye selection screen of the customization menu onto an empty 64x64 skin-sized texture, in the given color. On a render layer with "light_emission" set to 15 this gives the player glowing eyes exactly where they chose. The eye selection screen requires the "palladium:customization/eye_selection" feature flag.

Settings:

Setting Type Description Required Fallback Value
color Color The color the selected pixels are drawn in. false /

Examples:

{"type":"palladium:eye_selection","color":"#ff0000"}

Static Texture

Always returns the same texture file. Exists so that places expecting a dynamic texture can still be given a plain one.

Settings:

Setting Type Description Required Fallback Value
texture Identifier The texture to use. true /

Examples:

{"texture":"example:textures/example.png"}

Armor Or Skin Texture

For models on the body, like claws. Uses the worn suit's texture where an active layer from "model_layers" draws over the given region, otherwise the skin. Match the region to the model's UVs.

Settings:

Setting Type Description Required Fallback Value
regions Integer[][] The areas of the texture sheet to check, each as [u, v, width, height] in pixels (a 64x64 sheet). Should cover the pixels your model samples. Defaults to the bottom of the left arm: [[40, 48, 4, 4]]. false [[40, 48, 4, 4]]
min_coverage Float How much of the region must be drawn (0 to 1) for the suit to count as covering it. 1 means every pixel. false 1.0
model_layers string[] The model layer names that count as a suit, like "suit_chestplate" in "palladium:player#suit_chestplate". false [suit_chestplate]

Examples:

{"type":"argon:armor_or_skin"}

Chest Armor Texture

Uses the texture of the player's active "suit_chestplate" render layer, so an overlay like argon:female_chest always matches the worn suit. Shows the missing texture if no such layer is active.

Examples:

{"type":"argon:chest_armor"}

Secondary Eye Selection Texture

Like palladium:eye_selection, but for the pixels picked on the eye screen's "Secondary" tab, so a pack can color a second set on its own. Needs the argon:customization/secondary_eye_selection flag.

Settings:

Setting Type Description Required Fallback Value
color Color The color the secondary pixels are drawn in. false -1

Examples:

{"type":"argon:eye_selection_secondary","color":"#00ffff"}

Mouth Selection Texture

Like palladium:eye_selection, but for the pixels picked on the eye screen's "Mouth" tab. A pixel is an eye or a mouth, never both. Needs the argon:customization/mouth_selection flag.

Settings:

Setting Type Description Required Fallback Value
color Color The color the mouth pixels are drawn in. false -1

Examples:

{"type":"argon:mouth_selection","color":"#ff8080"}
