Add Random Superpower

Adds a random superpower from the given list to the entity.

Settings:

Setting Type Description Required Fallback Value
powers Power ID(s) / Tag IDs or tags of powers to randomly pick from. true /

Examples:

{"type":"palladium:add_random_superpower","power":"example:my_power"}
{"type":"palladium:add_random_superpower","power":["example:my_power","example:my_second_power"]}
{"type":"palladium:add_random_superpower","power":"#example:my_power_tag"}

Change Size

Animates the entity's size to the target value using the given size change type's duration and easing.

Settings:

Setting Type Description Required Fallback Value
size_change_type Identifier The size change type defining the transition duration, easing, and min/max bounds. true /
size Float / Value The target size to transition to. true /

Examples:

{"type":"palladium:change_size","size_change_type":"palladium:default","size":2.0}

Conditional Action

Runs an action based on the outcome of a condition

Settings:

Setting Type Description Required Fallback Value
condition Condition | Condition[] The condition(s) that define the action that will run. true /
on_false Action | Action[] The action(s) that are being run when the condition is false false /
on_true Action | Action[] The action(s) that are being run when the condition is true false /

Examples:

{"type":"palladium:conditional","condition":{"type":"palladium:crouching"},"on_true":{"type":"palladium:run_command","command":"say Is crouching!"},"on_false":{"type":"palladium:run_command","command":"say Is not crouching!"}}

Dash

Pushes the entity horizontally in the direction it is facing, scaled by a velocity modifier. Unlike Leap it ignores whether the entity looks up or down, so the push stays level, and it adds to the entity's current movement. Negative values push backwards.

Settings:

Setting Type Description Required Fallback Value
velocity_modifier Float / Value How strongly the entity is pushed, in blocks per tick. Can be a Value, for example one that reads a data attachment. true /

Examples:

{"type":"palladium:dash","velocity_modifier":1.2}

Modify Number Data Attachment

Applies an arithmetic operation to a numeric data attachment on the entity.

Settings:

Setting Type Description Required Fallback Value
attachment Data Attachment ID The ID of the data attachment to modify. true /
operation "+" | "-" | "*" | "/" | "%" The arithmetic operation to apply. true /
value (Dynamic) Value The operand value. true /

Examples:

{"type":"palladium:modify_number_data_attachment","attachment":"example:my_attachment","operation":"+","value":5}

Directional Leap

Like palladium:leap, but sets the velocity to your look direction scaled by the velocity modifier instead of adding to it, so the leap always goes where you aim.

Settings:

Setting Type Description Required Fallback Value
velocity_modifier Float The multiplier applied to the entity's look direction when this action runs. true /

Examples:

{"type":"argon:directional_leap","velocity_modifier":2.0}

Jump

Launches the entity straight up like a jump, keeping its sideways movement. A normal jump is about 0.42 and gets roughly 1.25 blocks; 0.8 gets roughly 4.5.

Settings:

Setting Type Description Required Fallback Value
velocity Float The upward speed, in blocks per tick. true /
additive Boolean Whether the speed is added to the entity's current vertical speed instead of replacing it. false false

Examples:

{"type":"argon:jump","velocity":0.8}

Ride

Mounts the entity you look at once. "ride_target" has you ride it; "target_rides_player" puts it on top of you instead (toggled off if triggered again).

Settings:

Setting Type Description Required Fallback Value
mode "ride_target" | "target_rides_player" Which of the two mounts the entity into: "ride_target" (user rides target) or "target_rides_player" (target rides user). true /
range Double How far away, along the user's line of sight, an entity can be to be targeted. true /

Examples:

{"type":"argon:ride","mode":"ride_target","range":8.0}
