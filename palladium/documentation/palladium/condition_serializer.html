Ability Animation Timer Value

Checks if the given animation timer in an ability has a certain value.

Settings:

Setting Type Description Required Fallback Value
min Integer | Time String ("40s", "2m", etc.) The minimum required value of the current animation timer value of the ability false /
max Integer | Time String ("40s", "2m", etc.) The maximum required value of the current animation timer value of the ability false /
ability Ability Reference The ability that is being checked on. true /

Examples:

{"type":"palladium:ability_animation_timer_value","ability":"example:power#ability_key","min":5,"max":10}

As Client Player

Evaluates the given conditions against the client player (the player viewing the game) instead of the context entity. Useful for render layers that should only appear based on the viewing player's state. Only works on the client. On the server, this condition always returns false.

Settings:

Setting Type Description Required Fallback Value
conditions Condition | Condition[] List of conditions to evaluate against the client player true /

Examples:

{"type":"palladium:as_client_player","conditions":[{"type":"palladium:crouching"}]}

As Source

Checks the given conditions for the source entity instead of the entity itself. The source is the entity that caused something to happen to the current entity, like the attacker in action on hit, area actions, beams, blasts and the final attack of combo attacks, or the shooter of a custom projectile. Without a source, this condition is not fulfilled.

Settings:

Setting Type Description Required Fallback Value
conditions Condition | Condition[] The condition(s) that are checked for the source. true /

Examples:

{"type":"palladium:as_source","conditions":[{"type":"palladium:crouching"}]}

As Target

Checks the given conditions for the target entity instead of the entity itself. The target is the entity that was affected, like the hit entity in action on hit, area actions, beams, blasts, the final attack of combo attacks and custom projectiles. These already check their conditions for the target, so this is mostly useful inside of an as source condition. Without a target, this condition is not fulfilled.

Settings:

Setting Type Description Required Fallback Value
conditions Condition | Condition[] The condition(s) that are checked for the target. true /

Examples:

{"type":"palladium:as_target","conditions":[{"type":"palladium:crouching"}]}
