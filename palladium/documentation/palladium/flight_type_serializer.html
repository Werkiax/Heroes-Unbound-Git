Default Flight

Default flying type. If the sprint speed is equal or less than the normal speed, this flight will be levitation-only.

Settings:

Setting Type Description Required Fallback Value
forced Boolean If enabled, the entity starts flying as soon as the flight ability is enabled and can't stop on its own. Double jumping and touching the ground won't end the flight, only disabling the ability or getting into a vehicle does. false false
sound Identifier Looping sound played constantly while flying. If propelled_sound is set as well, the two sounds fade between each other depending on whether the entity is in propelled flight. false /
sprint_speed Float The sprinting flight speed. If not set, it will be equal to the normal speed. false /
screen_shake Screen Shake Screen shake applied while the entity is in propelled flight. false /
propelled_sound Identifier Looping sound played while the entity is fast-flying (sprinting). Volume scales with flight speed. false /
speed Float The normal flight speed. true /
propelled_start_sound Identifier Sound played once when the entity enters propelled flight. false /

Examples:

{"type":"palladium:flight","speed":1,"sprint_speed":2,"screen_shake":{"intensity":{"yaw":0.8,"pitch":0.8,"roll":0.2},"frequency":0.35,"fade_in":12,"fade_out":15,"easing":{"in":"out_sine","out":"out_sine"}},"propelled_sound":"palladium:player.flight.propelled"}

Swinging

Allows the entity to swing from anchor points, similar to a grappling hook.

Settings:

Setting Type Description Required Fallback Value
beam_renderer Identifier | Beam Renderer (right_arm, left_arm) The beam renderer(s) used for the swinging rope. Can be a single identifier or separate right/left arm identifiers. false /
attach_sound Identifier Sound played for nearby players each time a new anchor attaches. false /
max_anchor_height_type "absolute" | "relative" Determines if the maximum height for anchors are relative to the ground, or a fixed y-level. false RELATIVE
swing_sound Identifier Looping sound played while the entity is swinging on an anchor. Volume scales with movement speed. false /
max_anchor_height Integer The maximum height for anchor points. true /
swing_interval Integer | Time String ("40s", "2m", etc.) The airborne gap (in ticks) between releasing one web and firing the next. The first web after starting the flight always fires at the apex of the launch boost. false 10
radius Float | Vector 2D The web length range: how far ahead anchors are placed and the maximum rope length. A single number or an array of 2 numbers (min/max). While flying, holding jump raises and holding shift lowers the height that new anchors are placed at. true /

Examples:

{"type":"palladium:swinging","max_anchor_height":20,"radius":[5.0,10.0],"beam_renderer":{"right_arm":"namespace:beam_right_id","left_arm":"namespace:beam_left_id"}}

Controlled Flight

Flight with momentum, banking and a body that leans into its travel direction. Speed still comes from "speed" and "sprint_speed". Toggling, speed levels, landing and takeoff work like palladium:flight.

Settings:

Setting Type Description Required Fallback Value
flight_entity_collision_damage Float Multiplier on the damage dealt to an entity that is flown into. false 1.0
flight_response_curve Float Shapes acceleration over speed. 1 is constant, above 1 starts slower and pushes harder near top speed (0.1 to 4). false /
sound Identifier Ambient flight sound. false /
enable_flight_collision Boolean Whether hitting a block or an entity at speed hurts. Off by default. false false
enable_speed_fov Boolean Whether the field of view widens with flight speed. false false
gravity_wrap_pitch Float How steeply the player has to be flying up or down, in degrees (30 to 80), before gravity turns. false 55.0
enable_gravity_following Boolean Whether gravity turns with the flight so loops and vertical flight have no pitch limit. Past gravity_wrap_pitch it turns 90 degrees about the player's right side and goes back to normal when flight ends. false false
enable_barrel_roll Boolean Whether double-tapping left or right while flying does a barrel roll that way. Off by default. false false
barrel_roll_min_speed Float The fraction of top speed needed to start a roll. false 0.2
camera_bank_multiplier Float The share of the bank the camera rolls by in partial mode. false 0.15
momentum_retention Float How much turning is held back at speed. 0 turns as sharply at speed as when slow, 1 holds the heading the most. false /
flight_impact_speed Float The impact speed in blocks per tick below which a collision does nothing. false 0.45
dive_pullout_responsiveness Float How much easier turning is above top speed, so pulling out of a dive doesn't need a huge circle (1 to 4). false 1.8
gravity_turn_ticks Integer How many ticks the camera and model take to turn with gravity. false 8
flight_collision_stop Boolean Whether an impact stops the player's speed. false false
propelled_sound Identifier Looping sound while propelled. false /
barrel_roll_camera_influence Float How much of the roll the camera follows, 0 keeps the view steady and 1 rolls with the body. false 0.0
landing_speed_threshold Float The downward speed, in blocks per tick, up to which a landing is controlled. Faster than this the flight doesn't brake and touching the ground is a hard landing. false 1.0
profile "controlled" | "propelled" | "natural" | "gliding" Presets every setting below: controlled is the balanced default, propelled has heavier momentum and sinks when no direction is held, natural turns and stops quickly with no gravity, gliding keeps momentum and sinks when slow. false CONTROLLED
lean_full_speed Float Fraction of top speed at which the body is fully aligned with the direction of travel. false 0.6
screen_shake Screen Shake Screen shake while propelled. false /
air_braking_strength Float Fraction of speed lost each tick when no direction is held (0 to 1). false /
camera_roll_mode "none" | "partial" | "full" How much of the bank the camera follows. false PARTIAL
barrel_roll_cooldown Integer Ticks before another roll can start. false 30
max_bank_angle Float The largest bank angle in degrees. false 30.0
propelled_start_sound Identifier Sound played once when propelled flight starts. false /
landing_recovery_duration Integer Ticks of recovery on the ground before flight stops after a landing. Moving cancels it early. false 15
hover_stabilization Float Extra fraction of speed removed each tick when almost stopped, so the player settles into a hover. false /
flight_entity_knockback Float How hard a hit entity is knocked away. false 0.5
barrel_roll_duration Integer How many ticks the roll takes. false 14
sprint_speed Float The sprinting (propelled) flight speed. Unset, sprinting does nothing special. false /
bank_speed_influence Float How much the bank scales with speed, 0 banks the same at any speed. false 0.7
enable_body_rotation Boolean Whether the player's body leans into the direction of travel while flying. false true
enable_superhero_landing Boolean Whether flight lands by itself when dropping toward the ground: soft touchdown, upright body, stop after the recovery time and no fall damage. Faster than landing_speed_threshold is a hard landing instead. false true
orientation_responsiveness Float How quickly the body follows the direction of travel each tick. false /
barrel_roll_lateral_strength Float A sideways push in the roll direction, as a fraction of top speed. false 0.3
enable_third_person_framing Boolean Whether the third person camera frames the body while flying, so the character stays near the middle of the screen however the body leans. First person is unchanged. false true
bank_responsiveness Float How quickly the bank builds each tick. false 0.25
bank_recovery_speed Float How quickly the bank returns to level each tick. false 0.12
speed Float The normal flight speed. true /
enable_flight_banking Boolean Whether the body rolls into turns. false true
glide_energy_exchange Float Gliding profile only. How much speed is traded for height. Dropping adds speed, climbing costs it (0 to 0.3). false 0.05
flight_block_collision_damage Float Multiplier on damage from hitting a block, worked out from the impact speed like elytra damage. false 1.0
lean_start_speed Float Fraction of top speed at which the lean begins. false 0.15
speed_fov_multiplier Float How much the field of view widens at top speed. false 0.12
dive_momentum_decay Float The fraction of extra dive speed lost each tick at full retention (0.001 to 0.3). The extra speed never lets the player pass the dive speed and always fades. false 0.015
dive_pitch Float How far down the player must look, in degrees (30 to 85), for a dive to start. It builds to full at 85. false 45.0
dive_speed_retention Float How much extra dive speed carries on after the dive. 0 loses it at the normal deceleration, 1 loses it at dive_momentum_decay. false 0.8
turn_responsiveness Float The heading change in degrees per tick when turning at low speed. false /
flight_acceleration Float Fraction of the gap to the target speed closed each tick when speeding up (0.001 to 1). false /
flight_deceleration Float Fraction of the gap closed each tick when slowing down while a direction is held (0.001 to 1). false /
hover_velocity_threshold Float Speed below which hover stabilization starts, scaled by 3. false 0.03
glide_lift_speed Float Gliding profile only. The fraction of top speed at which gravity is fully cancelled. Slower than this the player sinks (0.05 to 1). false 0.6
dive_acceleration_multiplier Float The top speed of a full dive as a multiple of the normal top speed (1 to 4). false 1.6
third_person_framing_offset Float How far above the middle of the body the third person camera aims, in blocks. Positive puts the character a little below the screen middle, 0 puts the body center on it (-1 to 2). false 0.25
landing_damage_reduction Float How much fall damage from a hard landing is prevented (0 to 1). It is dealt as fall damage, so Palladium's fall protection still applies. false 0.5
enable_diving Boolean Whether looking steeply down while pushing forward is a dive. A dive can reach dive_acceleration_multiplier times top speed and the extra speed fades slowly, so pulling out keeps momentum. There is no key, it follows the look direction. false false
gravity_influence Float How much gravity pulls while no direction is held, or always for the gliding profile, where it fades as speed rises (0 to 1). false /

Examples:

{"type":"argon:controlled_flight","speed":1.5,"sprint_speed":3,"profile":"natural"}

Forced Flight

Flight matching Palladium's default movement and animation, except the entity can never land or toggle out. It only stops when the granting ability is disabled.

Settings:

Setting Type Description Required Fallback Value
sprint_speed Float The sprinting flight speed, defaulting to the normal speed when unset. false /
propelled_sound Identifier Looping sound played while fast-flying (sprinting), its volume scaling with flight speed. false /
screen_shake Screen Shake Camera shake while sprinting in flight. Only used when a sprint_speed is set. false /
speed Float The normal flight speed. true /

Examples:

{"type":"argon:forced_flight","speed":1,"sprint_speed":2}
